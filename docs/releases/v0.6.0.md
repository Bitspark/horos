# 0.6.0

First public release, with fresh Git history. Retains descriptor well-formedness,
value conformance, diagnostics and the original conformance oracle. Go, Rust and
TypeScript use public ontos 0.15.0; Python remains source-only validation.

Release qualification also repairs inherited checker bugs: diagnostics preserve
binary labels and recursion names, record/recursion checks carry the full scope
and depth, TypeScript rejects BOM-prefixed constructor labels, and Go/TypeScript
compare deep exact literals without recursive equality. These repairs implement
the existing structural-identity and bounded-checking contracts; the original
oracle is unchanged. Additional regression tests cover these cases.

The public package contains no proof-construction, proof-verification or witness
serialization APIs. Those earlier interfaces remain in the private history.
No aliases or fallback implementations are supplied. The supported TypeScript
entrypoints are the checker and `./diagnose`.

This release adds no generic slots, new descriptors, native type generators or
Function/Stream/Cell behavior. See [the model](../spec/horos.md) and
[distribution](../distribution.md) for the exact scope.
