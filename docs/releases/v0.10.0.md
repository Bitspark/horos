# horos 0.10.0

This breaking release adds finite higher-order kinds to the unified declaration
language. A parameter can accept a type constructor, including one whose inputs
are themselves constructors. Applications are fully saturated and return proper
types. `Data` refines proper types with a compositional data-only guarantee.

```text
Page<T> = { items: list<T>; next?: text; }
Wrapped<F: Type -> Type, T> = { value: F<T>; }
Compose<F: Type -> Type, G: Type -> Type, T> = F<G<T>>
```

Known constructor bindings retain their conditional guarantees: Page produces
Data for Data inputs, an ignored input need not taint a data result, and a Wire
result is not Data. Abstract constructors offer only their declared interfaces.
Every open definition and argument is checked before result simplification.

## Migration

- Use module revision 3. Parameters contain structured proper/constructor
  interfaces; declarations include a proper result claim. Revision 2 and the
  previous bound-only API are removed without compatibility readers or aliases.
- Use local/imported declaration references directly. An application contains a
  callee expression and a nonempty argument list. A zero-parameter declaration
  is a proper reference; a generic declaration can be passed as a constructor.
- Repin canonical documents after migration. Exact module bytes and declaration
  names retain identity; literals remain opaque and never become generic syntax.
- Use typed, checked specialization arguments from the same Program. Construct
  proper arguments and named-constructor handles through that Program; foreign
  or zero handles are rejected. DataDescriptor additionally requires a proven
  data-only result before existing ground WF/Conforms can consume it.
- Read the [canonical specification](../spec/declarations.md) and
  [Go API](../../core/go/declarations/README.md) for exact signatures and rules.

Partial application, constructor-valued results, type lambdas, kind variables
and conditional/intersection interfaces for abstract constructors remain
unsupported. Higher-order native encodings belong to separately qualified
Bittype mappings; they are not part of this release.

## Preserved boundaries

Ground Ontos/Horos values and conformance are unchanged. Data preservation does
not establish recursion guardedness. Capability hydration, transport, execution
and library protocols retain their existing owners. Function, Stream and Cell
remain ordinary libraries; no core behavior or adapter is introduced.

Only Go exposes declaration tooling. Rust and TypeScript retain their ground
APIs. Distribution versions stay aligned across npm, crates.io and the Go
module, with public Ontos 0.16.0 dependencies. Root v0.10.0 and core/go/v0.10.0
must identify the same accepted source.

The [maintained release process](../distribution.md) requires all six source
checks, exact-source rehearsal, immutable archives and fresh anonymous public
consumer verification. Authored higher-order judgments and an independent
bounded reference evaluator supplement existing ground conformance. The release
receipts identify the actual source and artifacts; this document alone is not
evidence of publication.
