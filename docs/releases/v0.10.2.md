# horos Go 0.10.2

The complete `horos.kinds` standard module is now authored in
[Horos source](../../core/go/declarations/standard/horos.kinds.horos). Bittype's
ordinary parser and canonical encoder prepare the module asset distributed with
this Go package. Horos embeds and decodes that asset, then uses its existing
module loader and general kind calculus for admission.

The Go-authored definition builders are removed. `Prelude()`, `PreludePin()` and
`PreludeImport()` retain their existing API. Primitive formation still selects
the ordinary standard Data declaration by module identity and scope; source
imports remain explicit. The revision-4 declaration model, kind definitions,
ground APIs and runtime boundaries retain their existing meaning.

Both the maintained source and generated asset ship in the Go module. Downstream
builds need no Bittype executable, source parser or runtime filesystem lookup.
The [standard module guide](../../core/go/declarations/standard/README.md)
describes generation and the separation of formation dependencies, imports and
source locations.

This delivery publishes only `core/go/v0.10.2`. npm and Cargo packages remain at
0.9.0, and Ontos remains 0.16.0. Rust and TypeScript continue to expose their
existing ground APIs; the portable module asset does not add declaration
implementations to those languages. No adapters or runtime bindings are added.

No validation/check workflow was run under the owner's current delivery rule.
Unrun checks are not reported as passing.
