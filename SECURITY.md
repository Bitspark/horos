# Security

Report vulnerabilities through this repository's private vulnerability reporting
feature. Include the affected version, descriptor/value reproduction, observed
outcome and expected outcome. Do not put credentials or private application data
in a public issue. Public issues are suitable for ordinary non-sensitive defects.

The [form contract](docs/spec/horos.md) documents finite checking limits and the
distinction between a mismatch and exhaustion. Conformance is a data-shape check;
it does not grant authority or execute a behavioral contract.
